# ケーキのローカル確認

webフォルダで `npm.cmd run dev` を起動し、
http://localhost:3000/local-preview/cake を開いてください。
別ポートで起動した場合はURLの3000を表示された番号に置き換えます。

ログイン・Supabaseの設定や登録・コミットは不要です。
既存のEditorHost・Viewer・設定パネルをそのまま使っています。
クリームの色、画像のサイズ・位置・回転・明るさ・彩度、元に戻す/やり直す、
視点リセット、ローカルのギミック定義の設定項目を確認できます。
透過画像の透明部分は保持します。ギミックの動作自体はプレビューしません。
保存（Ctrl+Sを含む）・購入・ダウンロードは無効です。
選択した画像はアップロード/保存されず、ページを再読み込みすると消えます。

これはFBXベースの静止プレビューです。Unityのマテリアルの基本色を反映し、
独立したTextureオブジェクトにプリント用素材を設定しています。
Prefabの全変更・炎のパーティクル・配布用UnityPackageの完成確認ではありません。
FBX内の静止炎メッシュは残しています。個別のPrefab配置・UV調整は未完了です。

ページと素材配信はdevelopmentモードかつlocalhostのURLだけに限定しています。
共有データベースは読み書きしません。任意の原本や.envを配信する機能はありません。
公開用templatesフォルダにはまだ追加していません。

以前の簡易HTMLは比較用に残していますが、現在のURLでは使用しません。
画面が切り替わらない場合は開発サーバーをCtrl+Cで止めて再起動し、ブラウザを再読み込みしてください。
