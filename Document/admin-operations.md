# 運営の対応手順

管理画面は `/admin`。`profiles.is_admin` が true のアカウントだけが開ける（ほかの人には 404 になる）。
管理者にするには、Supabase の SQL Editor で次を実行する。

```sql
update public.profiles set is_admin = true where id = (select id from auth.users where email = '<メールアドレス>');
```

## トークンの問い合わせ

1. `/admin/users` でメールアドレスか表示名を検索し、ユーザーの詳細を開く
2. 「トークンの履歴」と「ダウンロード」で、問い合わせの内容を確認する
   - 二重消費: 同じ作品・同じ時刻にダウンロードの記録が 2 件あり、両方でトークンが減っているか
   - 不具合: ダウンロードの記録があるのに、パッケージが壊れていた・作られていなかったか
3. 「トークンの手動調整」で補填する
   - トークン数: 増やすなら正の数（有効期限 180 日のトークンを新しく付与する）
   - 理由: 必ず書く（例: 「二重消費の補填（問い合わせ #12）」）。履歴に操作した管理者と一緒に残る
   - 関係する ID: 補填の原因になった購入の ID（ダウンロードの表の右端）か支払いの ID
4. 誤って付与した分を戻すときは、負の数で調整する（有効期限が近いものから減らす。残高が足りなければ失敗する）

## お金の返金（不具合でダウンロードできなかった場合など）

1. Stripe のダッシュボードで、その支払いを返金する（全額または一部）
2. Webhook（`charge.refunded`）で、その支払いで付与したトークンのうち未使用の分が自動で取り消される
3. 使用済みの分は戻らない。不具合の影響を受けた分をトークンで補う場合は、上の手動調整を使う

## 購入した版の控えを消してほしいと言われた場合

利用者自身がダウンロード履歴の版の詳細から「この版の控えを削除」で消せる。消した版はダウンロード履歴から再ダウンロードできなくなる（購入の記録は残る）。
作品が残っていて内容が同じなら、エディタからは無料で作り直してダウンロードできる。

## 削除に失敗したファイル

`/admin` の「未完了のファイル削除」に一覧が出る。「未完了の削除を再試行」で再試行する。
本番では Vercel Cron が 1 日 1 回 `/api/cron/storage-deletions` を呼んで再試行する（環境変数 `CRON_SECRET` が必要）。10 回失敗したものは自動では再試行しないので、エラーを見て対応する。

## 作品・アカウントの停止

`/admin/users` で利用者を検索し、詳細画面から必要な範囲で止める。

- ダウンロード（購入した版）の「停止」: その版はダウンロード履歴から再ダウンロードできなくなる
- 作品の「公開停止」: 作品の編集・ダウンロードができなくなる
- 「アカウントを停止」: 購入・ダウンロードができなくなる

すでに VRChat に上げられたワールドや、BOOTH などでの販売は運営からは消せない。

停止・解除は、`admin_actions` に操作した管理者と一緒に記録される。

## テンプレート・ギミックのトークン数と公開状態

`/admin/catalog` で変える。登録済みのものは、templates:sync / gimmicks:sync を実行しても上書きされない（ファイルの値は初回の登録だけに使う）。非公開のテンプレートは、管理者だけがエディタ（`/editor/<slug>`）で確認できる。
