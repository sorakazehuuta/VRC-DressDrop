# VRPrintLab 要件定義書

## 1. プロジェクト概要
ブラウザ上で3Dモデル（展示用プロップ）に画像を貼り付けて編集し、VRChatでそのまま使える形式(.unitypackage)でダウンロードできるWebサービス。
VRChat内の即売会・展示イベントで、初心者でも「自分のグッズの3Dサンプル」を手軽に用意できるようにする。
サービスの範囲: テンプレート選択 → 編集 → 保存 → トークン決済 → ダウンロード → VRChatへの導入ガイド まで。

## 2. 既存の課題
### 2.1 3Dモデル制作の難易度が高い
モデリング・UV・テクスチャ・Unityの知識が必要で、初心者には参入障壁が高い。
### 2.2 VRChat内での物販が制限されている
同人誌やグッズなどの実物販売はリアルイベントが中心。VRChat内で商品の見た目を伝える手段が乏しい。

## 3. 課題の解決
### 3.1 初心者でも扱える制作環境
画像のアップロードと簡単な調整だけで、VRChatで使える展示プロップを作れる。
### 3.2 VRChat内イベントでのリアルグッズの販促
作成したモデルを即売会ワールドのブースに置き、実物グッズのサンプルとして展示できる。

## 4. ターゲットユーザー
- 主: VRChat内イベントに出展する同人作家・グッズ制作者（Unityは初心者〜中級者）
- 副: 自分のワールドやイベントを飾りたい一般のVRChatユーザー

## 5. スコープ
### 5.1 MVPに含むもの
- ワールド展示用プロップのテンプレート（初期: Tシャツ、アクリルスタンド、タペストリー、ポスター、缶バッジ）
- 画像貼り付け・調整、色変更、プレビュー
- .unitypackage の生成とダウンロード（PC/Quest 両対応）
- ギミック（UdonSharp の既製スクリプト）の付与
- アカウント、保存・再編集、トークン、PayPal決済、管理画面
### 5.2 MVPに含まないもの（将来検討）
- アバターに着せる衣装（ボーン・アバターごとの対応が必要なため）
- 痛車などの大型オブジェクト
- ユーザーによる任意の3Dモデルのアップロード
- 任意スクリプトのアップロード
- VRChatへの直接アップロード

## 6. 機能要件
### 6.1 テンプレート選択
- カテゴリ・サムネイル・消費トークン数を一覧表示する
- テンプレートごとに「印刷面(Print)」と「ベース面(Base)」のマテリアルスロットを持つ。複数の印刷面（表・裏など）にも対応する

### 6.2 3Dモデル編集
- 画像アップロード（PNG/JPEG、透過PNG対応、最大10MB、長辺4096pxまで。サーバーで最大2048pxに縮小する）
- 印刷面ごとの画像の割り当て
- 拡大縮小（X/Y、縦横比の固定）、位置、回転
- ベース色の変更（カラーピッカー）、明るさ・彩度などの簡易色調整
- 3Dプレビュー（回転・ズーム・リセット）
- 元に戻す／やり直す
- 未ログインでも編集・プレビューは可能（保存とDLにはログインが必要）

### 6.3 ギミック付与（オプション・追加トークン）
- 既製の UdonSharp ギミックから選択する: 回転、持ち上げ(Pickup)、表示ON/OFF切替、画像の切替 など
- ギミックごとに消費トークンを設定する
- パラメータ（回転速度など）は画面上で設定する
- ギミックを付けたパッケージは UdonSharp を必要とする旨を明示する

### 6.4 保存・再編集
- 作品（編集パラメータ＋元画像）をアカウントに保存する
- 作品一覧、複製、削除、名前の変更
- 無料ユーザーが保存できる作品数に上限を設ける（例: 20件）

### 6.5 ダウンロード
- .unitypackage をサーバー側で生成する（ブラウザ内で生成するとトークン消費を回避できてしまうため）
- 同梱物: FBX、マテリアル(PC用/Quest用)、テクスチャ、Prefab、（ギミックを付けた場合）U#スクリプト、README
- 配置先パス: `Assets/VRPrintLab/<作品名>/`
- 「DL権(購入済みの版)」の考え方:
  - DL時にトークンを消費し、その時点の編集内容を「購入済みの版」として確定する
  - 購入済みの版は何度でも無料で再DLできる
  - 編集内容を変えた場合は新しい版として再びトークンを消費する（ギミックの追加だけなら差分のトークンのみ消費する）
- DLの前に消費トークン数の内訳を表示し、確認を取る

### 6.6 ユーザー登録・管理
- メール認証、Google、Discord ログイン
- プロフィール（表示名）、パスワード再設定、退会（データ削除）
- 新規登録時にトークンを付与する（例: 3トークン）

### 6.7 トークン管理
- 残高表示、履歴（付与・購入・消費・失効）
- 消費量 = テンプレートのトークン数 ＋ 付与したギミックのトークン数の合計
- 有効期限: 購入・付与から180日未満（資金決済法の適用外とするため）。古いものから先に消費する
- 残高と履歴はサーバー側でのみ変更する（トランザクションと監査ログ付き）

### 6.8 トークン購入
- PayPal（Orders API v2）
- パック販売（例: 5 / 12 / 30トークン。まとめ買いほど割安）
- 付与は Webhook でサーバー側から検証してから行う（冪等性を担保する）
- 原則として払い戻さない（規約に明記する）

### 6.9 導入ガイド
- VCC/ALCOM によるプロジェクト作成 → unitypackage のインポート → Prefab の配置 → アップロード、までを画像付きで説明する
- PC/Quest の切替手順、ギミック使用時の UdonSharp 導入手順

### 6.10 管理機能
- テンプレートの登録・編集（モデル、スロット定義、消費トークン、公開/非公開）
- ギミックの登録・編集
- ユーザー検索、トークンの手動付与・調整（理由の記録を必須とする）
- 通報された作品・画像の確認と停止
- 売上・DL数の簡易集計

## 7. 非機能要件
- 対応ブラウザ: Chrome / Edge / Safari / Firefox の最新版（PC推奨。スマホは閲覧程度）
- 生成物は Unity 2022.3 LTS と VRChat SDK3 Worlds で動作すること
- Quest の制約: VRChat/Mobile 系シェーダー、テクスチャ最大2048px、1プロップあたり1万ポリゴン以下を目安とする
- パッケージ生成は10秒以内
- セキュリティ: Supabase の RLS、アップロードファイルの MIME/中身の検証、署名付きURLによるDL、レート制限
- 可用性: 個人開発の水準（SLAは設けない）。DB は日次でバックアップする

## 8. 法務・規約
- 利用規約: アップロード画像の権利はユーザーが保証すること、他人の著作物・肖像・公序良俗に反するコンテンツの禁止、違反時にアカウントを停止すること
- 特定商取引法に基づく表記
- プライバシーポリシー
- 資金決済法: トークンの有効期限を6か月未満とし、前払式支払手段の届出を不要とする
- 生成物の利用範囲: 作成者は VRChat 内外で自由に使える。テンプレートのモデルを単体で再配布することは禁止する

## 9. システム構成
- フロントエンド: Next.js (App Router, TypeScript), Three.js (react-three-fiber)
- バックエンド: Next.js Route Handlers
- 認証・DB・ストレージ: Supabase (Auth / Postgres / Storage)
- 決済: PayPal Orders API v2 + Webhook
- ホスティング: Vercel
- unitypackage の生成: サーバー側で tar.gz を組み立てる（既存試作 index.html のロジックを移植）

## 10. データモデル（概要）
- users (Supabase Auth) / profiles
- templates: id, name, category, model_path, slots(json), token_cost, is_public
- gimmicks: id, name, script_path, params_schema(json), token_cost
- works: id, user_id, template_id, params(json), gimmick_ids, updated_at
- work_images: id, work_id, slot, storage_path
- purchases (購入済みの版): id, work_id, params_hash, token_spent, created_at
- token_lots: id, user_id, amount, remaining, source(grant/purchase/admin), expires_at
- token_transactions: id, user_id, delta, reason, ref_id, created_at
- payments: id, user_id, paypal_order_id, amount_jpy, tokens, status
